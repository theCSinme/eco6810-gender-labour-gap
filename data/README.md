# Data Documentation

## Study Period

2019–2023.

## Data Sources

The project uses World Bank World Development Indicators (WDI) labour-force participation indicators:

- **Male labour-force participation rate, ages 15 and above:** `SL.TLF.CACT.MA.ZS`
- **Female labour-force participation rate, ages 15 and above:** `SL.TLF.CACT.FE.ZS`

The indicator data were obtained through DataHub's distribution pages for World Bank WDI data:

- Male indicator: https://datahub.io/world-development-indicators/sl.tlf.cact.ma.zs
- Female indicator: https://datahub.io/world-development-indicators/sl.tlf.cact.fe.zs
- World Bank API documentation: https://datahelpdesk.worldbank.org/knowledgebase/topics/125589

Country metadata and income-group classifications were obtained from the World Bank Countries API.

The source CSV files are retained in `raw/`. The prepared analysis dataset is stored in `analysis_dataset.csv`. The final analysis script reads the prepared dataset and does not require a live API connection to execute.

## Files

- `analysis_dataset.csv`: Prepared country-year analysis dataset used by the analysis script.
- `country_year_gender_gap.csv`: Derived country-year dataset containing the calculated gender gap, generated by the analysis script.
- `raw/male_lfp.csv`: Source data for male labour-force participation.
- `raw/female_lfp.csv`: Source data for female labour-force participation.
- `raw/country_metadata.csv`: Country metadata and income-group classifications.

## Outcome Construction

The gender gap is calculated as:

**Gender gap = Male labour-force participation rate − Female labour-force participation rate.**

Both input indicators are measured as percentages. Their difference is therefore expressed in **percentage points**, not as a percentage change.

A positive value indicates that male labour-force participation exceeds female labour-force participation.

## Sample Construction

The analysis covers 2019–2023 and retains country-year observations for which the required male and female participation indicators and country metadata are available.

The prepared dataset contains 931 country-year observations across 187 countries. The panel is unbalanced because not every country has usable observations for every year.

The analysis uses the income-group classifications recorded in the prepared dataset. These classifications should not be interpreted as historically reconstructed income groups for every year.

The precise rules used to exclude non-country aggregates should be interpreted in conjunction with the filtering logic in the analysis script.

## Income Groups

Income groups are based on World Bank classifications recorded in the country metadata used to prepare the analysis dataset. The project compares high-income, upper-middle-income, lower-middle-income, and low-income groups.

## Reproducibility

The repository retains the prepared analysis dataset, the downloaded source CSV files, the analysis script, and generated outputs. The documented run command is:

`uv sync`

followed by:

`uv run main.py`

The analysis should be reproducible from the committed inputs and the documented environment, provided the dependency lockfile is current and the script completes successfully.
