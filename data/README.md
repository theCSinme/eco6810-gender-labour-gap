
# Data Documentation

## Study period

2019–2023.

## Sources

The project uses World Bank World Development Indicators (WDI).

- Male labour-force participation rate, ages 15 and above: `SL.TLF.CACT.MA.ZS`
- Female labour-force participation rate, ages 15 and above: `SL.TLF.CACT.FE.ZS`

Indicator data are available through the World Bank API and DataHub.

- Male indicator data: https://datahub.io/world-development-indicators/sl.tlf.cact.ma.zs
- Female indicator data: https://datahub.io/world-development-indicators/sl.tlf.cact.fe.zs
- World Bank API documentation: https://datahelpdesk.worldbank.org/knowledgebase/topics/125589

Country metadata and income-group classifications are sourced from the World Bank Countries API.

## Files

- `analysis_dataset.csv`: Prepared country-year analysis dataset.
- `country_year_gender_gap.csv`: Country-year dataset containing the calculated gender gap, when generated by the analysis script.
- `raw/male_lfp.csv`: Source data for male labour-force participation.
- `raw/female_lfp.csv`: Source data for female labour-force participation.
- `raw/country_metadata.csv`: Country metadata and income groups.

## Outcome construction

The gender gap is calculated as:

Male labour-force participation rate − Female labour-force participation rate.

Both input indicators are percentages. Their difference is therefore expressed in percentage points, not as a percentage change.

## Sample construction

The analysis retains country-year observations for which both male and female participation rates and the required country metadata are available.

Regional aggregates are excluded where identifiable from the source metadata.

## Income groups

Income groups are based on the World Bank classification recorded in the country metadata used by the project. They should not be interpreted as historical income classifications for each individual year.
